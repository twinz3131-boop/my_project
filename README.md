# Test Data Generator

Генератор тестовых данных на Python: имена, email-адреса,
телефонные номера, адреса и даты рождения. Поддерживает
две локали (RU/EN), сохранение в CSV и JSON, валидацию
сгенерированных данных.

## Возможности

- Генерация реалистичных данных:
  - ФИО с учётом пола (`Кузнецов Дмитрий Сергеевич` /
    `Кузнецова Анна Ивановна`);
  - email на основе имени (`dmitriy.kuznetsov@yandex.ru`);
  - телефоны в формате страны;
  - адреса с индексом, городом, улицей, домом и квартирой;
  - даты рождения в реалистичном диапазоне.
- Локали: `ru` и `en`.
- Выбор полей: можно запросить только те, что нужны.
- Экспорт: CSV (`utf-8-sig` для Excel) и JSON
  (`ensure_ascii=False`).
- Валидация: проверка формата и диапазона дат.
- Воспроизводимость: параметр `--seed`.
- CLI и интерактивный режим.
